# 第一章 土的物理性质与分类

## 1. 土的物理性质与分类

### 岩石风化的产物

**定义**：土是地球表面岩石经风化作用形成的碎散颗粒群体，由土骨架及其孔隙中的水与气体组成。

**循环过程**：岩石→风化→土→沉积压密→沉积岩→风化→土...（沧海桑田循环）

**工程土特点**：90%以上为第四纪（Q）形成的土体，距今时间从几千年到百万年不等。

#### 年代划分：

全新世（$Q_4$）：距今1.3万年以内

- 早期（$Q_{4-1}$）：1.3-0.75万年
- 中期（$Q_{4-2}$）：0.75-0.25万年
- 晚期（$Q_{4-3}$）：<0.25万年

更新世（Qp）：距今1.3-71万年

- 晚更新世（$Q_3$）：12.8-1.3万年
- 中更新世（$Q_2$）：71-12.8万年
- 早更新世（$Q_1$）：>71万年

工程特性：

- 全新世中晚期（$Q_{4-2}$、$Q_{4-3}$）土体：欠固结，强度低（如湿陷性黄土）
- 更新世（$Q_3$-$Q_1$）土体：固结程度高，强度好（$Q_1$土体接近岩石硬度）

### 风化作用类型

- 物理风化：

  - 特点：机械破坏，颗粒由大变小（量变）
  - 产物：原生矿物（石英、长石、云母）
  - 工程表现：砂土、碎石土（亲水性差，无粘结性）
  - 影响因素：温度变化、冻融、盐结晶、应力释放

  化学风化：

  - 特点：矿物成分改变（质变）
  - 产物：次生矿物（高岭石、蒙脱石等黏土矿物）
  - 工程表现：黏性土（亲水性强，可塑性好）
  - 反应类型：
    - 水解：正长石→高岭石
    - 水化：﻿$\mathrm{CaSO_4}$﻿→﻿$\mathrm{CaSO_4·2H_2O}$﻿
    - 氧化：﻿$\mathrm{FeS_2}$﻿→﻿$\mathrm{FeSO_4·7H_2O}$﻿

  生物风化：

  - 植物根系作用
  - 动物洞穴作用
  - 人类工程活动影响

### 土的工程分类依据

  - 沉积年代：Q4与Qp土体强度差异显著
  - 矿物组成：
    - 原生矿物：颗粒大，亲水性差（如砂土）
    - 次生矿物：颗粒小，亲水性强（如黏土）
  - 风化程度：
    - 物理风化为主→粗粒土
    - 化学风化为主→细粒土
