### 1.1 利息的计算

#### **1.1.1 利息和利率**

1.1.1 利息和利率

1.利息的含义

利息=还本付息总额-本金

不包括：<span class="font-jcysxh">评估费、保险费、诉讼费、保全费等。</span>

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763010536717.png" style="zoom:33%;" />

2.利息的本质

• 对资金供给方(债权人)放弃一定时期资金使用权的补偿，是资金供给者的报酬(收益)，同时
也是资金需求者使用资金的代价(成本)。

• 利息来源于资金发挥运营职能而产生的增值。

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763010625199.jpg" style="zoom:33%;" />

3.利息对经济活动的影响

|     影响企业行为     | 利息是资金使用成本，本质来源于利润。利息水平与企业生产经营利润水<br/>平比较，<span class="font-jcysxh">会直接影响企业资金筹措决策</span> |
| :------------------: | :--------------------------------------------------------------------------------------------------------------------------------------- |
| 影响居民资产选择行为 | 消费、储蓄、投资？                                                                                                                       |
|     影响政府行为     | 通过利息(利率)调节微观主体(企业、居民)行为，从而进行宏观经济<br/>调控                                                                    |

4.利率

| 含义  | $利率=\dfrac{利息}{本金}\times100\%$<br><span class="font-jcys">利息</span>是资金收益或使用代价的<span class="font-jcys">绝对数</span>，<span class="font-jcys">利率</span>是资金收益或使<br>用代价的<span class="font-jcys">相对数</span>，<span class="font-jcys">表示资金的增值程度</span>。 |

1.1.2 利息的计算方法

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763011983022.jpg" style="zoom:33%;" />

<span class="font-jcysxh">1.单利计息，利不生利</span>

每计息周期利息=本金×利率

<span class="font-jcysxh">2.复利计息，利滚利</span>

每计息周期利息=上期末的本利和×利率

已知：本金100元，年利率5%，存款3年(计息周期数)

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763012048329.jpg" style="zoom:70%;" />

3年末本利和：

单利=本金+本金×利率×计息周期=100+100×5%×3=115

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763012097677.jpg" style="zoom:50%;" />

公式推导

第1年末的本利和$=100+100×5\%=100×(1+5\%)$

第2年的利息$=100×(1+5\%)×5\%$

第2年的本利和$=100×(1+5\%)+100×(1+5\%)×5\%$

$=100×(1+5\%)× (1+5\%)$

$=100×(1+5\%)^2$

复利计算和单利计算结果的比较：

①同一笔借款，在利率和计息周期(大于1)均相同的情况下，用复利计算出的利息金额要比单利计
算出的利息金额<span class="font-jcysxh">多</span>。

<span class="font-jcysxh">②本金越大，利率越高，计息周期越多，两者的差距就越大</span>。

③在工程经济分析中， 一般采用<span class="font-jcysxh">复利</span>计息方式计算。

④按期(年、 半年、季等)计算复利的方法称为<span class="font-jcysxh">间断复利</span>(即普通复利)，按瞬时计算复利的方法
称为<span class="font-jcysxh">连续复利</span>。在实际使用中采用<span class="font-jcysxh">间断复利</span>。

**1.3.3 等值计算公式应用要点**

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763047741134.jpg" style="zoom:60%;"/>

<span class="font-jcysxh">公式变形：</span>

|    用途    |             计算公式             |
| :--------: | :------------------------------: |
| 已知P，求F |           $F=P(1+i)^n$           |
| 已知F，求P |         $P=F(1+i)^{-n}$          |
| 已知A，求F |     $F=A\dfrac{(1+i)^n-1}i$      |
| 已知F，求A |     $A=F\dfrac i{(1+i)^n-1}$     |
| 已知A，求P | $P=A\dfrac{(1+i)^n-1}{i(1+i)^n}$ |
| 已知P，求A | $A=P\dfrac{i(1+i)^n}{(1+i)^n-1}$ |

应用资金等值计算应注意以下要点：

1.合理选取收益率 i

资金安排：“晚付早收”。

2.正确认识等值计算系数的作用

运用等值计算系数进行资金等值计算<span class="font-jcysxh">不会导致预计或实际现金流量发生时间（时点）发生变动，也不会改变现金流量的方向。</span>

4.严格遵循现值P、终值F、年金A等值换算之间的相对关系

“标准公式”使用前提条件：

（1）A发生在计息期的<span class="font-jcysxh">期末</span>。

（2）当问题包括P和A时，系列的第一个A是在P发生一个期间后的期末发生的；当问题包括F和A时，系列的最后一个A与F同时发生。

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763049901757.jpg" style="zoom:50%;" />

5.计息周期小于资金收付周期时等值计算的处理

（1）按收付周期实际利率计算；

（2）按收益率（利率）i的时间单位（计息周期）计算。

**两笔绝对金额不相等的资金、在不同时间点。在资金时间价值的作用下,如果在某个时间点上是等值的，则在利率不变的情况下，两笔资金在其他任何时间点上也是等值的。**

应当获得的<span class="font-jcysxh">最低盈利率水平</span>。

1.评价指标直接对比法

评价指标直接对比的方法要求所选用的指标是价值型。

<span class="font-jcysxh">计算期相同</span>

<span class="font-jcysxh">方法一：财务净现值</span>

步骤：①计算财务净现值

②剔除小于0的方案

③比较大于0的方案

④财务净现值最大的方案为最佳方案

<span class="font-jcysxh">方法二：费用年值指标</span>

当收益相同，可采用费用现值指标和费用年值指标。

选择<span class="font-jcysxh">小</span>的方案。

2.增量指标分析法

比较两个方案之间的<span class="font-jcysxh">“增量”</span>

如果增量方案<span class="font-jcysxh">可行</span>，选择投资额大的方案。

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763226248421.jpg" style="zoom:65%;" />

如果增量方案<span class="font-jcysxh">不可行</span>，选择投资额小的方案。

（1）计算步骤

①投资额排序：小→大

②确定基础方案，即满足指标评判准则要求的投资额较小的方案（临时最优方案）

④保留方案与下个方案比较，重复

⑤确定最优方案

### 3.2 敏感性分析

**3.2.1 敏感性分析的概念和分类**

敏感性分析是用以考察方案涉及的<span class="font-jcysxh">各种不确定因素</span>对方案经济效果<span class="font-jcysxh">评价指标</span>的影响，找出敏感因素，估计方案效益对它们的敏感程度，粗略预测方案可能承担的风险，为进一步的风险分析打下基础。

敏感因素：仅发生<span class="font-jcysxh">较小幅度的变化</span>就能引起经济效果评价指标<span class="font-jcysxh">发生大的变动</span>。

敏感性分析可分为<span class="font-jcysxh">单因素敏感性分析</span>和<span class="font-jcysxh">多因素敏感性分析</span>。

1.单因素敏感性分析是指<span class="font-jcysxh">每次只改变一个不确定因素</span>的数值，估算单个不确定因素的变化对方案经济效果产生的影响。

2.多因素敏感性分析则是<span class="font-jcysxh">同时改变两个或两个以上</span>相互独立的不确定因素的数值，估算多个不确定因素同时发生变化对方案经济效果的影响。

敏感性分析方法对方案<span class="font-jcysxh">财务分析和经济分析</span>同样适用。

3.2.2 敏感性分析的方法与步骤

1）确定分析指标

<span class="font-jcysxh">财务净现值、财务内部收益率、静态投资回收期</span>

2）选择不确定性因素（建设投资、汇率、销售价格等）

<span class="font-jcysxh">准确性把握不大的、影响较大的因素</span>

3）计算不确定因素的变化对分析指标的影响

5）对敏感性分析结果进行分析

### 4.2 设备经济寿命确定

**4.2.1 设备寿命类型**

**自然寿命**

设备从全新状态<span class="font-jcysxh">投入</span>使用直到因实体磨损严重而不能继续使用、<span class="font-jcysxh">报废</span>为止所经历的全部时间，主要是由设备<span class="font-jcysxh">有形磨损</span>所决定的；<span class="font-jcysxh">不能成为设备更新的决策依据</span>。

**技术寿命**

设备从投入使用到因<span class="font-jcysxh">技术落后而被淘汰</span>所延续的时间，主要是<span class="font-jcysxh">无形磨损决定，</span>一般比自然寿命短。<span class="font-jcysxh">技术进步越快，技术寿命越短。</span>

**经济寿命**

设备从全新状态<span class="font-jcysxh">投入</span>使用开始，到继续使用在<span class="font-jcysxh">经济上不合理</span>而<span class="font-jcysxh">被更新</span>所经历的时间，由<span class="font-jcysxh">有形磨损和无形磨损</span>共同决定。

**4.2.2 设备经济寿命的估算**

**1.确定的原则**

（1）使设备在经济寿命内<span class="font-jcysxh">平均每年净收益（纯利润）达到最大</span>；

（2）使设备在经济寿命内一次性投资和<span class="font-jcysxh">各种经营费总和达到最小</span>。

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763228397870.jpg" style="zoom:45%;" />

设备目前实际价值：<span class="font-jcysxh">新设备</span>包括购置费和安装费，<span class="font-jcysxh">旧设备</span>包括旧设备<span class="font-jcysxh">现在的市场价值</span>和继续使用旧<span class="font-jcysxh">设备追加的投资</span>。

每年的设备运行成本：包括人工费、材料费、能源费、维修费、停工损失、废次品损失等。

2.确定方法

（1）公式计算法（静态方法）

<span class="font-jcysxh">年平均使用成本</span>=年平均资产消耗成本+年平均运行成本

$$\dfrac{目前实际价值-N年末残值}{使用年限} \dfrac{\sum年运行成本}{使用年限}$$

低劣化数值法：

通常随着设备使用期限增加，年运行成本每年以某种速度在递增，<span class="font-jcysxh">这种递增的运行成本称为设备的劣化</span>。

若每年运行成本的<span class="font-jcysxh">增量是相等</span>的，则<span class="font-jcysxh">运行成本呈线性增长</span>。

$$设备的经济寿命=\sqrt{\dfrac{2\times(目前实际价值-预计净残值)}{设备的劣化值}}$$

**5.1.2 价值工程的特点**

1.价值工程能有效实现对象<span class="font-jcysxh">技术和经济的结合</span>；

2.价值工程基于<span class="font-jcysxh">用户/顾客</span>（消费者）视角解决问题—物有（超）所值；

①功能必须是消费者需要的功能

<img src="https://tupian-d290.obs.cn-east-3.myhuaweicloud.com/img/1763230820806.jpg" style="zoom:60%;" />

②价值工程的费用（成本）是指<span class="font-jcysxh">寿命周期成本</span>，即从对象的研究、形成到退出使用所需的全部费用。

3.价值工程的<span class="font-jcysxh">目标</span>是<span class="font-jcysxh">提高</span>对象的<span class="font-jcysxh">价值</span>；

价值工程的“价值”是功能与费用（成本）的<span class="font-jcysxh">比较价值</span>，体现的是功能与成本之间的协调关系。

4.价值工程活动的<span class="font-jcysxh">核心</span>是<span class="font-jcysxh">功能分析</span>；

5.价值工程强调技术方案创新；

以产品为对象实施价值工程时，<span class="font-jcysxh">重点应放在产品的研发和设计阶段。</span>

6.价值工程需要进行量化分析；

7.价值工程是一种有组织的管理活动。

成立价值工程工作组，确定项目负责人，以<span class="font-jcysxh">集体智慧</span>开展有计划、有组织、有领导的管理活动。
