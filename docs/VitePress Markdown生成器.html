字段说明

文件设置

  • 文件名: 包含.md扩展名的文件名，生成的内容将以此名称保存
  • 编码格式: 所有生成的文件均采用UTF-8编码，确保多语言兼容性
  • 文件操作: 支持复制为文件和下载两种方式获取生成的内容

核心字段说明

  • 标题 (title):

    文档的主标题，会显示在页面顶部、浏览器标签以及导航菜单中

  • 布局 (layout):

    指定页面使用的布局模板，常用值包括：

    • doc - 标准文档布局（默认值）
    • page - 简化的页面布局，无侧边栏
    • home - 首页布局，适合展示项目介绍
    • 404 - 错误页面布局
  • 排序 (order):

    用于确定页面在侧边栏导航中的位置，数值越小越靠前显示，未设置则按文件名排序
