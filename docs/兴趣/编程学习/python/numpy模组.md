# numpy模组

## arange函数

np.arange(start, stop, step) (开始，结束，步长)与原本python原本的range函数方法类似。

np.array() 将列表或字典转化为数组。

np.zeros() 生成全为零的数组，括号内输入行数和列数。

np.ones() 效果和上面差不多，生成全为1的数组，用法和上面一样。

np.empty() 创建一个未初始化的数组，用法和上面一样, 创建的数组会包含随机数。
